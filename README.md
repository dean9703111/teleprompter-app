# 提詞器 Teleprompter

一個基於 React + Vite 的純前端提詞器網頁應用，提供直覺易用的提詞功能，並支援「智慧跟讀」：念到哪裡，稿子就捲到哪裡。

## 功能特色

### 核心功能
- ✅ **文字輸入與編輯** - 直覺的文字輸入介面
- ✅ **自動滾動播放** - 使用 `requestAnimationFrame` 實現平滑滾動
- ✅ **播放控制** - 播放/暫停按鈕，一鍵開始提詞
- ✅ **速度調整** - 1-20 級速度控制，即時調整滾動速度
- ✅ **字體大小調整** - 35-100px 字體大小，適應不同觀看距離
- ✅ **全螢幕播放模式** - 沉浸式黑底白字提詞體驗

### 進階功能
- 🎙️ **智慧跟讀** - 用瀏覽器內建語音辨識（Web Speech API）聽你念稿，稿子與辨識結果都轉成拼音比對，相似度達 70% 就捲到你念到的位置
  - 依你的語速連續捲動，不會一行一行跳；已念過的文字變暗，接下來要念的字標成黃色
  - 可調整目前念到的位置停在畫面的高度（10–60%）
  - 數字用中文念也對得上（2024年 ↔ 二零二四年、35% ↔ 百分之三十五），容許同音錯字、破音字與 zh/z、ing/in 口音
  - 支援脫稿、跳段落、回頭重念；手動捲動後會以畫面位置重新定位
  - 支援 Chrome、Edge、Safari（Firefox 不支援）；Chrome / Edge 的語音辨識在雲端進行，需要網路
- 📊 **智能字數統計** - 分別統計中文字數、中文標點、英文單詞、英文標點、總行數
- 🎭 **繞柱排版** - 0-30% 可調間隔寬度，支援左右分欄顯示（繞柱子效果）
- ✂️ **智能段落分割** - 10-200 字元可調，自動將長句分段，保持英文單詞完整
- ⏱️ **預計完成時間** - 即時顯示剩餘播放時間
- 📈 **進度條顯示** - 底部進度條，隨時掌握播放進度

### 使用者體驗
- 🎯 **極簡介面** - 首頁只有輸入框和開始按鈕，專注內容
- ⌨️ **快捷鍵支援** - 完整快捷鍵操作，無需觸碰滑鼠
- 📱 **響應式設計** - 桌面版完整控制列，手機版抽屜式設定面板
- 💾 **設定記憶** - 自動儲存速度、字體、間隔、分段、跟讀位置等所有設定
- 🎨 **現代化 UI** - Material UI 組件，漸層背景，顏色編碼統計卡片
- 👤 **作者資訊** - 整合社群連結（Facebook、GitHub、Medium、YouTube）

### 快捷鍵
- `空白鍵` - 播放/暫停（跟讀中則停止跟讀）
- `M` - 開關智慧跟讀
- `↑/↓` - 調整速度 ±1（跟讀時調整跟讀位置 ±5%）
- `+/-` - 調整字體大小 ±5px
- `ESC` - 退出全螢幕
- `滑鼠滾輪` - 手動控制滾動位置

## 智慧跟讀

### 使用方式
1. 貼上講稿後按「開始提詞」
2. 按工具列的麥克風「跟讀」按鈕（或按 `M`），第一次使用時允許瀏覽器使用麥克風
3. 開始照稿念，畫面會依你的語速連續捲動，念過的文字變暗、接下來要念的字標成黃色（工具列的螢光筆按鈕可關閉高亮）
4. 左側藍色箭頭是「跟讀位置」，可在工具列的「位置」滑桿或用 `↑/↓` 調整
5. 想從其他段落開始，直接用滾輪 / 手指捲到該段落再開口念即可；畫面上看得到的文字（包含標題）念出來都能直接對上；按空白鍵停止跟讀

### 運作原理
- 語音辨識使用瀏覽器內建的 Web Speech API（中文稿用 `zh-TW`，英文稿用 `en-US`）
- 講稿與辨識結果都轉成無聲調拼音，用最後約 10 個音節在稿子裡做模糊比對（半全域編輯距離），相似度達 70% 才捲動，避免辨識錯字或脫稿時亂跳
- 數字轉成中文念法再比對：`2024年` → 二零二四年、`35%` → 百分之三十五、`3.5` → 三點五、`1,000` → 一千；「兩」視同「二」
- 容許台灣口音常見的 zh/z、ch/c、sh/s、ing/in、eng/en 不分，英文允許 `ChatGPT` ↔ `chat GPT` 這類拆字差異
- 破音字的任一讀音都算對上（例如「行」的 xing / hang）
- 附近對不上時會改做全文搜尋（門檻 85%），所以跳段落、回頭重念也能跟上
- 從最近幾秒的比對結果估算語速，在兩次辨識結果之間持續往前推估位置（並補償約 0.4 秒的辨識延遲），停頓時就停住、不會倒退
- Chrome 一直講不停頓約 17 秒後就不再回傳辨識結果，所以只要還在講話（麥克風聽得到人聲）卻 2 秒沒有新的辨識文字，就自動重開辨識；重開後約需數秒才接得上，這段期間畫面依語速繼續往下捲（最多 10 秒），辨識恢復後再校正，不會往上跳

### 注意事項
- 支援 Chrome、Edge、Safari；Firefox 不支援 Web Speech API 的語音辨識
- Chrome / Edge 會把聲音送到雲端辨識，需要網路連線
- 需在 HTTPS 或 `localhost` 下才能使用麥克風

## 技術規格

### 技術棧
- **框架**: React 19 + TypeScript
- **建構工具**: Vite
- **UI 框架**: Material UI (MUI)
- **樣式**: Emotion (CSS-in-JS)
- **語音辨識**: Web Speech API（瀏覽器內建）
- **拼音轉換**: [pinyin-pro](https://github.com/zh-lx/pinyin-pro)（支援繁體中文）
- **已讀高亮**: CSS Custom Highlight API（不修改 DOM）
- **Node 版本**: 22.6.0

### 效能優化
- 使用 `requestAnimationFrame` 確保流暢滾動
- 文字分段渲染，避免長文字卡頓
- 拼音字典（約 140KB gzip）只在開啟跟讀時才動態載入，不影響首頁速度
- 已讀高亮使用 CSS Custom Highlight API，跟讀時不重新渲染文字
- LocalStorage 儲存使用者設定
- 響應式設計適配各種裝置

## 安裝與啟動

### 需求
- Node.js 22.6.0 或更高版本
- npm 或 yarn

### 安裝步驟

1. **安裝依賴**
   ```bash
   npm install
   ```

2. **啟動開發伺服器**
   ```bash
   npm run dev
   ```

3. **建構生產版本**
   ```bash
   npm run build
   ```

4. **預覽生產版本**
   ```bash
   npm run preview
   ```

5. **執行測試**
   ```bash
   npm test
   ```

## 部署

### GitHub Pages 部署

本專案使用 GitHub Actions 自動部署到 GitHub Pages：

- 僅在 `master` 分支觸發部署
- 自動建構並部署到 `gh-pages` 分支
- 部署 URL: `https://[username].github.io/teleprompter-app`

### 手動部署

1. 建構專案：
   ```bash
   npm run build
   ```

2. 將 `dist` 資料夾內容部署到任何靜態網站託管服務
